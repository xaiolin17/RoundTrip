## 0. 一句话结论

**重跑校准证明了「按实测重排权重」这条路走不通 —— 不是因为实测结果不好，
而是因为校准结果根本进不到权重里。**

`data/source_ir.json` 写什么都被兜底覆盖。所以"重跑校准"对权重是**空操作**。
这一点已被实验证实（§3），不是我推测的。

> 而修好之后暴露的真相更严重 —— **四个源没有一个通过加了对照的判定门**，
> 所以"让校准生效"的直接后果是**系统不开仓**（§10）。

## 3. 决定性实验：写校准文件**改变不了任何权重**

我构造了一份"没有任何源通过"的校准文件，喂给 `WeightTable.load()`：

| 源 | 当前权重 | 写入后权重 | 是否相同 |
|---|---|---|---|
| kalman_persist | 4.0000 | 4.0000 | 是 |
| chanlun | 0.1276 | 0.1276 | 是 |
| classic_indicators | 0.0459 | 0.0459 | 是 |
| openmobius_smc | 0.0000 | 0.0000 | 是 |

**权重完全不变。** 原因在 `weights.py` 的合并策略：

```python
for name, ir in BASELINE_IR.items():
    cur = tbl.sources.get(name)
    if cur is not None and cur.verified:
        continue                      # 只有文件里 verified=True 才用文件
    if ir > 0:
        tbl.sources[name] = SourceIR(..., ir=ir, verified=True, ...)
```

文件里三个源都是 `verified=False` → 全部被 `BASELINE_IR` 覆盖：

```
kalman_persist 0.28 / chanlun 0.05 / classic_indicators 0.03
```

### 结论

**校准文件对三个真实源是"装饰性"的。** 无论 `research/21` 测出什么，
只要没有源通过非重叠门，权重就永远等于 `BASELINE_IR`。

> 因此**"重跑校准再按实测重排"这条路在当前代码下是走不通的**。
> 真正的杠杆只有一个：`weights.py` 里的 `BASELINE_IR` 常量表。

## 5. 附带发现 B：判定门本身没有足够功效

### 5.1 门槛的检力只有 50%

门要求"观测到的 t > 1.5"。但 t 统计量在原假设下 sd≈1，于是：

| 真实 t | 通过门的概率 |
|---|---|
| 0.00 | 6.7% |
| 1.00 | 30.9% |
| **1.50** | **50.0%** ← 门自己的门槛 |
| 2.34 | 80.0% |
| 3.00 | 93.3% |

**一个真实 t 恰好等于门槛（1.5）的源，被接受和被拒绝的概率一样大。**
要达到 80% 检力需要真实 t ≥ 2.34。

### 5.2 纯噪声有 14% 概率通过

喂进**纯随机方向**（每根 bar 随机 ±1，零信息）跑 100 次：

```
t_ind: 均值 -0.023   sd 1.246   范围 [-3.91, +2.43]
P(噪声通过 t>1.5)   = 14.0%
P(噪声通过 t>1.645) =  9.0%
```

**纯噪声有 14% 的概率通过这道门。**

### 5.3 方向偏差未被控制

窗口是趋势市（全多头毛收益 −0.4644/笔，全空头 **+0.5690**/笔）。
一个持续偏空的源**不需要任何预测能力**就能拿到正 t 值。

用"同多空比例、随机位置"的对照检验四个源的 t 值落在什么分位：

| 源 | 观测 t | 对照均值 | 对照 sd | 分位 | 判定 |
|---|---|---|---|---|---|
| kalman_persist | +0.31 | +0.56 | 1.01 | 45.0% | 可由方向偏差解释 |
| classic_indicators | +0.17 | +0.52 | 1.02 | 37.0% | 可由方向偏差解释 |
| chanlun | +0.67 | +0.59 | 1.07 | 53.5% | 可由方向偏差解释 |
| openmobius_smc | +2.19 | +0.52 | 1.09 | 93.0% | 可由方向偏差解释 |

**四个源全部落在方向匹配对照的分布内部** —— 包括那个"通过"的桩。
即：**这道门没有把"方向偏差"和"预测技能"分开。**

`21_source_ir.py` 在 A 段确实做了三种对照（随机方向/匹配多头/块置换），
但 `verified` 判定（L517-519）**只用 `tb_gross_nw_t_ind`**，没接入任何对照。

## 6. 那权重到底该怎么办？

**本次没有改动 `BASELINE_IR`，也没有翻转权重排序。** 理由：

1. **没有可信的实测排序可用。** 四源全部落在方向偏差对照之内，
   非重叠检力只有 50%、噪声通过率 14% —— 这个样本**无法分辨**排序。
   用 `chanlun(0.0069) > kalman(0.0001)` 这类数字去重排，
   等于用噪声替换手填数字，正是 P0-2 要消灭的事。
2. **早期研究结论方向相反。** `11_mechanism.txt`（三种独立对照确认
   kalman_trend 毛 NW-t=+3.31）支持 kalman 最强；本次校准不支持。
   这个矛盾需要更大样本或更好的检验来解决，不是改个常量能了结的。
3. **盲目翻转有实际风险。** 把 kalman 从 95.8% 降到 2%，等于让系统
   主要听从一个从未被独立验证过的源。

**已做的**（行为中性，只让问题可见）：`weights.py` 现在在启动时告警
"3 个源在校准文件里未通过验证，但按兜底常数取得了权重"，并在
`describe()` 里报出 `basis` / `file_ir` / `file_verified` / `disagreement`。

## 9. 修改一：让校准结果真能影响权重

### 9.1 问题回顾

§3 已证明：写入一份"四个源全部未通过"的校准文件，权重**一模一样**。
根因是 `load()` 无条件用 `BASELINE_IR` 覆盖任何 `verified=False` 的源。

### 9.2 修法：新增策略开关

`config.toml` `[fusion].source_ir_policy`（也可用环境变量 `SOURCE_IR_POLICY`）：

| 取值 | 行为 |
|---|---|
| `baseline_fallback` | 文件未通过 → 用 `BASELINE_IR` 兜底常数。**校准无法影响权重**（旧行为，保留兼容） |
| `authoritative` | **文件判定即终审**：未通过 → 0 权重，无任何兜底。**当前生产设定** |

`WeightTable.load()` 新增 `policy=` 显式参数（优先于配置），
使测试不随 `config.toml` 漂移。

### 9.3 实测效果（同一份 `data/source_ir.json`）

| 源 | baseline_fallback | authoritative |
|---|---|---|
| kalman_persist | 4.0000 | **0.0000** |
| chanlun | 0.1276 | **0.0000** |
| classic_indicators | 0.0459 | **0.0000** |
| openmobius_smc | 0.0000 | 0.0000 |
| **合计** | **4.1735** | **0.0000** |
| σ | 0.4895 | ∞ |

**校准结果现在真的决定了权重。**

### 9.4 代价：当前校准下系统不开仓（这是刻意的）

总权重 0 → σ = 1/√0 = ∞ > `sigma_max` 0.8。已核对决策层的实际分支：

- `machine._decide_flat` → σ 超限 → `Proposal(kind="hold")`
- `machine._pending_cancel` → σ 超限 → **撤销挂单**

即失败模式是**「不开仓 + 撤挂单」**，不是崩溃，也不是乱开仓。
（已确认 `inf > 0.8` 为 True、无 NaN 参与比较；止损/止盈路径不读权重表，
持仓仍能正常管理。）

这是"如实反映实测证据"的代价。要恢复交易应当**改进信号源**，
而不是切回兜底常数 —— 后者正是本次要消灭的自我欺骗。

## 10. 修改二：把方向匹配对照接进判定门

### 10.1 旧门的漏洞

旧判定门只看 `非重叠毛 NW-t > 1.5`。但 §5.3 已证明本窗口是趋势市，
**持续偏空的源不需要任何择时能力就能拿到正 t**。三个证据：

1. 纯随机方向有 **14.0%** 的概率通过旧门；
2. 方向匹配置换对照的 t 均值本身就有 **+0.5** 量级；
3. 四个源全部落在对照分布内部（含那个"通过"的离线桩）。

### 10.2 新门

在原有三条之上**增加第四条**：

```
非重叠毛 NW-t > 1.5  且  非重叠毛均值 > 0  且  独立样本 ≥ 30
                                        **且  置换 p < 0.05**
```

对照的构造：把非重叠样本的**方向在其内部随机重排** ——
多空比例严格不变、收益路径严格不变，只打乱"哪个时点做哪个方向"。
重排 200 次得到零假设分布；用保守置换 p 值
`(1 + #{对照 ≥ 观测}) / (1 + 模拟数)`。

⚠️ **量纲陷阱（第一版写错过）**：`tb.ret` **已经带了源自己的方向**
（`ret[i] = sgn[i]·u[i]`）。所以置换必须写成 `perm * ret`，
**不能**写成 `d * ret` —— 后者是把收益取反而非打乱方向，
多空比例会跟着歪掉，对照就不"匹配"了。已加源码断言防回归。

⚠️ 随机种子必须**确定性**地从源名导出，**不能用内置 `hash()`**
（`PYTHONHASHSEED` 随机化会让同一份数据每次跑出不同结论）。

### 10.3 新门下的实测结果：**全部未通过，包括那个离线桩**

| 源 | 非重叠毛 NW-t | 独立样本 | 对照均值 | 置换 p | 判定 |
|---|---|---|---|---|---|
| kalman_persist | +0.31 | 376 | +0.50 | 0.577 | ❌ |
| classic_indicators | +0.17 | 380 | +0.52 | 0.622 | ❌ |
| chanlun | +0.67 | 316 | +0.51 | 0.398 | ❌ |
| **openmobius_smc** | **+2.19** | 371 | +0.45 | **0.075** | ❌ |

**关键**：连唯一"通过"旧门的离线桩也落选了（p=0.075 > 0.05）。
这印证了 §5.3 的判断 —— 旧门测到的多半是方向偏差，不是技能。
注意四个源的观测 t **全部低于**各自对照的均值。

### 10.4 这个结果意味着什么（别过度解读）

必须诚实说明：这不等于"证明了四个源都没有技能"。§5.1/§5.2 已证
这道门**本身功效不足**（门槛处检力仅 50%）且**纯噪声有 6.7% 概率通过**
（加对照后从 14% 降到接近名义水平）。

准确表述是：**在约 300 个独立观测的样本量下，没有任何源能提供
足以与"方向偏差 + 噪声"区分的证据。** 要下"源无效"的结论，
需要更大的独立样本（§7 第 1 条：约 2.5 倍）。

## 11. 修改三：DL 收缩取代策略开关（并修掉一个方向反转的耦合）

### 11.1 为什么 `authoritative` 也是错的

§9 把策略改成了 `authoritative`，代价写得很清楚："四个源全未通过 → 总权重 0
→ 系统不会开仓"。用户 2026-09-29 指出这不是可接受的结果：

> 要恢复交易 但是有合理的处理方式吗 不能放一个没有作用的死代码在那吧
> 我这是商用项目欸

这个批评成立，而且根因比"选哪个策略"更深。`baseline_fallback` 与
`authoritative` **都必然留下一段死代码**：

| 策略 | 死代码 | 后果 |
|---|---|---|
| `baseline_fallback` | 校准文件（永不影响权重） | 校准脚本等于空跑 |
| `authoritative` | `BASELINE_IR`（永不被读取） | 系统不开仓 |

根因：**把统计估计做成了二值开关**。

### 11.2 数据到底说了什么

用 DerSimonian-Laird 估计量做方差分解（三个可测源）：

```
skill_i = t_i − 方向匹配对照均值_i          # 超出"方向偏差"的真实技能
        = −0.19 / −0.35 / +0.17
Q = Σ(skill_i − mean)² = 0.14187,  df = k−1 = 2
tau² = max(0, (Q − df)/C) = 0      (因为 Q < df)
lambda = tau²/(tau² + s²) = 0
```

**`tau² = 0` 的含义：观测到的源间差异不比纯抽样噪声更大。**
既然数据分辨不出源的高下，那么**任何**按这组数据重排权重的公式
都是在拟合噪声 —— 包括"按实测 IR 排序加权"。

这与 §5 的功效分析一致：独立样本仅 316~380，双侧 α=0.05 下要 80% 功效
需要真实 t ≥ 2.80，而实测最大 t 只有 0.67。**分辨不出来，不是测不出东西。**

### 11.3 正确做法：精度加权收缩（经验贝叶斯）

把两个被焊在一起的问题拆开：

| 问题 | 性质 | 正确答案 |
|---|---|---|
| **可测性** `measurable` | 事实判断 | `openmobius_smc` 无历史回放 → **0 权重**（硬规则保留） |
| **技能差异** `lambda` | 估计量 | **永不做硬 0**，按 `lambda` 连续混合 |

```
w_i = lambda · w_measured_i + (1 − lambda) · w_prior_i

w_prior    = W_SCALE                    # 已知源等权（无信息先验的最大熵解）
w_measured = (max(0,skill_i)/skill_max)² · W_SCALE
lambda     = tau² / (tau² + s²)         # 由 DL 估计量从数据算出
```

`lambda` 是**权重**，不是开关 —— 两个端点在每个源上都真实参与计算。

### 11.4 可证伪性（这是"没有死代码"的证据）

`lambda` 不是被钉死在 0 的常量。k=3 时 `Q > df = 2` 即触发：

| skill = (−s, 0, +s) | Q | tau² | lambda | w(强源) | w(弱源) |
|---|---|---|---|---|---|
| s = 0.50 | 0.500 | 0 | 0.000 | 4.000 | 4.000 |
| s = 1.00 | 2.000 | 0 | 0.000 | 4.000 | 4.000 |
| s = 1.35 | 3.645 | 0.8225 | **0.451** | 4.000 | 2.195 |
| s = 2.00 | 8.000 | 3.0000 | **0.750** | 4.000 | 1.000 |

即：数据一旦能把源排出高下，实测排序**自动**接管权重，无需改任何配置。

### 11.5 恢复交易，但降仓表达"置信度低"

等权下 `Σw = 3 × 4.0 = 12.0` → `σ = 1/√12 = 0.2887 ≤ sigma_max 0.8`
→ 系统照常开仓。

但"分不出源的高下"意味着**置信度低**，正确的表达位置是**仓位**，
不是"开/不开"这个二值开关（把统计功效不足做成开关，正是本轮的病根）：

```toml
[decision]
uncalibrated_lot_mult = 0.5   # lambda < 0.5 时手数 ×0.5
```

`lambda ≥ 0.5` 后数据已能排序，本系数自动失效（恢复全仓）。
低置信度 → 小仓位；而不是零交易（一个不交易的交易系统不是安全，是失败）。

### 11.6 顺带修掉一个**方向反转**的耦合（用户指出）

用户原话：

> 本来要改的就是权重影响开仓 但是权重即会增大也会减小才对

这句话点出了旧实现的另一个缺陷。融合分是**加权平均**
`S = Σwμ/Σw`，故其尺度恰好是

```
sd(S) = 1/√Σw = FusionResult.sigma
```

而旧代码用**绝对常数**去比它：`abs(S_eff) >= open_threshold`。于是：

| 权重状态 | Σw | σ | `|S|≥1.3` 实际含义 |
|---|---|---|---|
| 旧冻结基线 | 4.17 | 0.4895 | \|z\| ≥ 2.66 |
| 等权收缩 | 12.00 | 0.2887 | **\|z\| ≥ 4.50** |

**权重越大（越有把握）→ 越难开仓。方向正好反了**，而且这个耦合是
隐式的：改权重时会静默改掉入场松紧，没有任何地方提示。

实测影响（60,000 根真实 1m bar，305 轮 × 2 段）：

| 权重 | 开仓率（旧绝对阈值 1.3） |
|---|---|
| Σw = 4.17（基线） | 12.3% / 21.3% |
| Σw = 12.0（等权） | **0.7% / 2.3%** ← 几乎不开仓 |

**这就是"恢复交易"没真正达成的原因** —— 不是权重带来的，是阈值尺度带来的。

修法：判定改用 **z 尺度** `z = S_eff / σ`，门槛取**当前实际生效**的
z（1.3/0.4895 = 2.66），故不改变入场松紧，只把耦合去掉。
修后权重的影响变成**双向且方向正确**：

| Σw | σ | 开仓率 |
|---|---|---|
| 6.0 | 0.4082 | 5.0% / 5.3% |
| 12.0 | 0.2887 | 15.7% / 16.0% |
| 24.0 | 0.2041 | 32.3% / 25.7% |
| 48.0 | 0.1443 | 49.0% / 43.3% |

单调递增 —— 权重真正成为"把握度"的杠杆。
