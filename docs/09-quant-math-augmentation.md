## 0. 执行摘要（先看这一节）

**结论一：现有系统的融合分 S 没有预测力。** 在 3,944 个真实决策点上，
S 与未来 5m/15m/30m/1h/2h/4h 收益的 Spearman IC 全部落在
`[-0.0145, +0.0105]`，方向命中率 `49.2%~50.0%`（随机 = 50%）。
各分项的 Newey-West 稳健 t 值全部 `|t| < 1.7`。**没有一个信号源通过显著性检验。**

**结论二：现有 σ（不确定度）是常数，不携带信息。** 实测 3,944 个点里 σ 只有
**2 个唯一值**（std = 1.09e-16）。原因是各源的 `sigma` 在 `fusion/engine.py`
里被硬编码为常数（0.5 / 0.6 / 0.8），逆方差加权因此退化成固定权重加权。
"分歧检测"阈值 `2σ_S` 也就失去了统计含义。

**结论三：Hurst regime 门控实际失效。** R/S 估计量在**纯随机游走**上就系统性
上偏到 **0.573**（实测对照），真实黄金 1m 收益是 **0.582** —— 两者只差 0.009。
生产用 `H>0.55` 判 trending，导致 **71% 的时间被误判为趋势市**（实盘日志印证：
604 轮里 trending 占绝大多数，mean_reverting 仅 0.1%）。regime 门控等于没开。

**结论四（最重要）：真正的瓶颈不是"模型不够多"，而是盈亏几何。**
当前实盘几何 TP=1.2×ATR / SL=0.78×ATR（config 的 2.0/1.2 经 shrink 0.6/0.65 后），
在随机游走下的理论胜率是 33.3%，而**含成本的盈亏平衡胜率是 46.4%**——
需要超越随机游走 **+13.1 个百分点**才能不亏。1 分钟周期下往返成本 0.52 USD
= **39% 的止损距离**。这是短线策略的数学现实。

> ⚠️ 这里的 39% 是**用 1m 波动定止损**时的数字（`research/23_kalman_tb.py`
> 在另一组 TP/SL 参数下测得 46%，同一现象的两次测量）。
> 止损改由 `risk.atr_tf = "1h"` 定尺度后，成本/止损降到 **2.5%**
> —— 见上方"结论四的落地方式已修正"。

**结论五：波动率是唯一稳健可预测的量。** GARCH(1,1) / EWMA 的 QLIKE 显著优于
滚动标准差；两状态 HMM 的高波动状态，其未来 2 小时平均绝对收益是低波动状态的
**1.60 倍**。波动率可用于**仓位与风控**（已验证：波动率目标化把最大回撤从
2167 降到 1634，Calmar 从 4.91 提到 5.32），但**不能用于方向**。

**由此得出的方案主轴**：不再往"方向预测"里堆模型（数学上已被证伪），而是把
增补的数学模型用于三件真正能改变盈亏的事——
**(A) 成本与执行**、**(B) 风险与仓位**、**(C) 拒绝交易（元标注门控）**。

**1m 收益 σ = 1.606 USD** ⇒ 往返成本 = **0.32 个 1m 标准差**。

### 1.2 统计检验（`research/01`, `02`）

**方差比检验（Lo-MacKinlay）** —— 1m 上唯一显著的发现：

| 周期 | q | VR | z | 判定 |
|---|---|---|---|---|
| 1m | 2 | 0.9859 | −3.46 | 随机游走边界 |
| 1m | 5 | 0.9749 | −2.81 | **均值回归** |
| 1m | 10 | 0.9500 | −3.63 | **均值回归** |
| 1m | 20 | 0.9440 | −2.76 | **均值回归** |
| 15m | 5 | 1.0150 | +0.48 | 随机游走（不显著） |

**但这个均值回归不可交易**（`research/03`）：把 z-score 反转策略做成实际交易，
扣掉 0.52 USD 往返成本后，**全部 16 个变体的 NW-t 都是负的**，最好的是 −3.66，
最差 −25.42。总盈亏 −10,000 ~ −51,000 USD/盎司。**统计显著 ≠ 可交易。**

**收益自相关**：lag 1/5/15/60/240 分别 `−0.0095 / +0.0058 / −0.0029 / +0.0049 / +0.0037`
—— 接近白噪声。**平方收益自相关**：`+0.0595 / +0.0219 / +0.0143 / +0.0108 / +0.0003`
—— 强波动聚集（GARCH 效应）。**可预测的是方差，不是方向。**

**AR(p) 样本外 R²**：1m 上 `+0.00006 / −0.00001 / +0.00096`；15m 上全为负。
线性方向可预测性为零。

**时段效应**：16 个 UTC 小时桶，最大 |t| = 2.68（11 时），
Bonferroni 校正后阈值 |t| > 2.8 ⇒ **无任何时段显著**。

### 1.4 障碍几何的结构性亏损（`research/08`）
用赌徒破产理论：障碍设 +aσ / −bσ，随机游走下先触 +a 的概率 = `b/(a+b)`。
先用**随机游走**验证标注实现（模拟 vs 理论）：

| 几何 | 理论胜率 | 模拟胜率 | 误差 |
|---|---|---|---|
| 2.0σ/1.0σ | 0.333 | 0.365 | 0.032 |
| 1.5σ/1.0σ | 0.400 | 0.434 | 0.034 |
| 1.0σ/1.0σ | 0.500 | 0.508 | 0.008 |
| 1.0σ/2.0σ | 0.667 | 0.635 | 0.032 |
| 3.0σ/1.0σ | 0.250 | 0.275 | 0.025 |

标注实现正确。**然后看真实成本下的平衡胜率**：

| TP(σ) | SL(σ) | 理论胜率 | 含成本平衡胜率 | 需要的边际 |
|---|---|---|---|---|
| 2.0 | 1.0 | 0.333 | **0.464** | **+13.1pp** ← 当前系统 |
| 2.0 | 1.5 | 0.429 | 0.540 | +11.2pp |
| 3.0 | 2.0 | 0.400 | 0.478 | +7.8pp |
| 4.0 | 2.0 | 0.333 | 0.399 | +6.5pp |

**解读**：把 SL 从 1σ 放宽到 2σ、TP 提到 4σ，所需边际从 +13.1pp 降到 +6.5pp。
**短线系统的正确优化方向是放宽止损 + 降低成本，而不是提高命中率。**

## 4. 选型：速度-精度 Pareto（`research/08`）

**用户要求："相似模型在准确上没有太大误差的时候选用执行快的。"**
已将其固化为显式规则：

```
选型规则
  R1  功能冗余组内，若 |Δ精度| < 0.005 且存在更快的同类 → 选最快者
  R2  精度差异显著 → 选精度高者，但单次计算必须 < 3s（1 分钟循环的 5%）
  R3  硬约束：单模型计算时间 > 10s 直接淘汰（无论精度）
```

**冗余分组**（数学上测量同一现象）：波动率水平 / 波动率风险 / 流动性成本 /
方向动量 / 状态 regime / 信息量 / 仓位。

**选型结果：保留 28 个，淘汰 7 个。**

| 淘汰模型 | 原因 |
|---|---|
| `vol_parkinson` | 精度 +0.2931 vs `vol_garman_klass` +0.2944，几乎相同，后者更快 |
| `ml_gbdt` | **10.31s > 10s 硬约束**（已优化到 109s→仍超标，直方图预分箱后 10.3s） |
| `fracdiff` / `fft_cycle` / `ema_cross_z` / `kalman_trend` | 方向类精度全在 ±0.03 内，冗余 |
| `mutual_info` | 精度 +0.0096 vs `kl_div` +0.0127，冗余且慢（2.49s） |

**性能预算**：保留模型合计 **14.1s**，占 1 分钟循环的 **23.6%**。

**关键优化**（本轮实测）：
- HMM：446s → **2.8s**（增量滤波 + 下采样 + 对数域递推）
- GBDT：196s → 109s → **10.3s**（预分箱直方图分裂，O(n·f) 替代 O(n·f·分位)）

### 5.3 误差分析：所有分档全部为负

| 维度 | 分档结果 |
|---|---|
| HMM 高波动概率 | Q1 −0.472 → Q4 −0.408（单调改善但全负） |

## 6. 增补方案（按商业价值排序）

> **核心判断**：不要在"方向预测"上继续堆模型。数学上已被证伪（第 3、5 节）。
> 增补的数学模型应服务于**成本、风险、拒绝交易**三件事。

### 优先级 P0 — 立即修复（不新增模型，只修错）

| # | 问题 | 修复 | 依据 |
|---|---|---|---|
| P0-1 | **σ 是常数**，逆方差加权退化为固定权重 | 每源 σ 由其**滚动预测误差**（EWMA 残差标准差）动态估计 | 第 0 节结论二 |
| P0-2 | **Hurst 阈值失效**（71% 误判 trending） | 用**随机游走基准校正**：对同长度随机游走估 H₀，用 H−H₀ 判定；或改用 2 状态 HMM | 第 0 节结论三；`hmm_high_vol` 已验证 |
| P0-3 | **障碍不随方向翻转**（已在本轮修复） | `quant/labeling.py` 已修正并加回归测试 | 第 1.4 节 |
| P0-4 | **NaN→int 溢出**污染收益（已修复） | 同上 | 第 1.4 节 |
| P0-5 | **成本未进入几何设计** | 把成本纳入 TP/SL 求解（见 P1-1） | 第 1.4 节 |

### 优先级 P1 — 盈亏几何重构（最高商业价值）

**P1-1 成本感知的障碍优化**

对每个 (TP, SL) 组合，用真实历史计算：
```
净期望 E = p·TP·σ − (1−p)·SL·σ − cost
平衡胜率 p* = (SL·σ + cost) / ((TP+SL)·σ)
真实边际 = 实际胜率 − p*
```
在 1m 上扫描网格，选**所需边际最小**且**实际可达**的几何。

**实测结论（第 1.4 节）**：把 SL 从 1σ 放宽到 2σ、TP 提到 4σ，
所需边际从 **+13.1pp 降到 +6.5pp**。这是**不增加任何模型**就能改善盈亏的最大杠杆。

**P1-2 执行方式优化（Almgren-Chriss）**

`ac_urgency` 模型（κ = √(λσ²/η)）已实现。用途：
- κ 高（波动大、流动性差）→ 市价成交，宁可付点差
- κ 低（波动小、流动性好）→ 挂单等待，赚点差

**挂单入场只付单边点差（0.26 而非 0.52），直接把成本减半。**
当前系统已经用网格挂单，但没有用模型决定"何时该挂单、何时该市价"。

**P1-3 成本门控**

用 `cs_spread` / `roll_spread` 实时估计有效点差，
当"成本 / 预期波动"超过阈值时**拒绝交易**。
实测 `cs_spread` 与未来绝对收益秩相关 **+0.2867**，是有效的成本状态量。

### 优先级 P2 — 风险与仓位（已验证有效）

**P2-1 GARCH 波动率目标化**（已验证）

`research/04` 实测（1h，3982 样本）：

| 方案 | 总盈亏 | 标准差 | 年化 Sharpe | 最大回撤 | Calmar |
|---|---|---|---|---|---|
| 固定仓位 ±1 | 10,648 | 45.85 | 4.54 | 2,167 | 4.91 |
| **GARCH 波动率目标** | 8,689 | **38.24** | 4.44 | **1,634** | **5.32** |

**波动率目标化把回撤降低 25%，Calmar 提升 8%。** 这是**不改变方向期望**就能
改善风险调整收益的标准手段，应替换现有的 `volatility_k()`。

**P2-2 HMM 状态门控**

`hmm_high_vol` 已实现（2.8s）。实测：
- 低波动状态：占 89.8%，σ=9.96bp，持续 5.7h
- 高波动状态：占 10.2%，σ=29.07bp，持续 1.0h
- **高波动状态的未来 2h 平均绝对收益是低波动状态的 1.60 倍**

用途：高波动状态下**降低杠杆**（而非禁止交易）；状态转换时**收紧止损**。

**P2-3 EVT 尾部风险**

`evt_hill` + `evt_es` 已实现。黄金超额峰度 **100.9**，尾部极厚。
用 Hill 尾指数动态调整止损宽度——尾部越厚，止损越要放宽（否则被跳空穿透）。

### 优先级 P3 — 元标注门控（已验证能降低亏损）

**P3-1 二级门控模型**

已实现并验证：元标注把 NW-t 从 −23.67 改善到 −3.15，亏损降低 7.4%。

**用途**：不是"预测方向"，而是"**决定这次信号要不要执行**"。
在方向信号无 alpha 的情况下，这是唯一能提升"精确率"的手段。

**P3-2 拒绝交易的三个数学判据**

| 判据 | 模型 | 实测依据 |
|---|---|---|
| 市场无序 | `entropy` 高 | 熵与未来收益相关 −0.0198 |
| 分布漂移 | `kl_div` 高 | 模型失效预警 |
| 成本过高 | `cs_spread` / `ac_urgency` | 与未来波动相关 +0.2867 |

### 优先级 P4 — 暂不采纳（附理由）

| 模型 | 不采纳理由 |
|---|---|
| 粗糙路径 / 分数布朗 | `rough_vol_hurst` 实测精度仅 +0.0495，且 3.14s 耗时；对方向无贡献 |
| Copula / 生存分析 | 单品种（XAUUSDm）无多资产依赖结构可用 |
| 图论 / 网络 | 同上，单品种无网络结构 |
| 博弈论 / 做市 | MT5 无盘口数据，无法建模 |
| 泛函分析 / 算子理论 | 无穷维优化对单品种短线无边际收益 |
| 组合数学 / 离散数学 | 二叉树定价已在 TP/SL 几何中隐含 |
| `ml_gbdt` | 精度 −0.0162（负），10.3s 超时，淘汰 |
| `fracdiff` `fft_cycle` `ema_cross_z` `kalman_trend` | 方向精度全在 ±0.03 内，冗余 |

## 9. 诚实的结论

1. **现有系统的方向预测能力为零**，这不是"参数没调好"，而是数学上被证伪的。
2. **1 分钟周期 + 0.52 USD 往返成本 + 1.33 USD 的 σ** ⇒ 成本占止损 39%，
   这是短线策略最硬的约束。
3. **增补模型的价值在成本、风险、拒绝交易三处**，不在方向预测。
4. **最大的单一改善杠杆是障碍几何**（放宽 SL），不需要任何新模型。
5. **在 L3–L7 通过之前，任何"提高盈利"的承诺都不可信**，也不应写进营销材料
   （NFA 2-29(c)(4) 已生效）。

**本方案给出的不是"更多模型"，而是"把数学模型用在正确的地方"，
以及一套能证明或证伪的验证体系。**
